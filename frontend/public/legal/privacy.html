Anayaa.AI Privacy Notice

Anayaa is designed as a local-first app. In the default setup, the app runs on your machine and your browser talks to http://127.0.0.1:8000.

Default Local-First Behavior

  • The web app is served locally.
  • User accounts are stored in local PostgreSQL.
  • Sessions, rate limits, and cache entries are stored in local Redis.
  • Scripture retrieval uses local corpus data and local Milvus Lite data.
  • Guidance synthesis uses local Ollama models unless optional cloud routing is configured.

Data Stored Locally

Anayaa may store login records, password hashes, session state, scrubbed submitted dilemmas, retrieved citations, guidance outputs, audit scores, feedback records, request metrics, and password-reset token hashes.

The browser stores the active JWT, login email, pseudonymous user key, and scrubbed recent question history in local storage. Logging out removes the active JWT, email, and user key, but retained local question history may remain for follow-up continuity.

Password Reset

Password reset codes and links are printed to the backend terminal for local-first account recovery.

Sensitive Information

Avoid entering highly sensitive personal information, including full private names, addresses, phone numbers, government IDs, medical record details, legal case details, and financial account details. Anayaa includes sanitizer and PII-scrubbing protections, but no automated filter is perfect.

Optional Cloud Routing

If you configure a cloud provider key, selected requests may be sent to that provider depending on routing settings. Do not enable cloud routing unless you understand and accept that provider's data handling terms.
